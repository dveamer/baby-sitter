
# 네이버 블로그 댓글 작성

wordpress-tasks.md 파일에 작성되어있는 tasks 들 중 5개를 뽑아서 각 tasks 에 적힌 블로그 글에 공감을 누르고 댓글을 달아줘. 댓글에 homepage-img-1-ko.png 이미지 파일도 첨부해줘. 

공감, 댓글, 이미지 첨부는 naver-blog-comment-assist skill 을 이용하면돼.

## 이미지 첨부 처리

티스토리 댓글 UI에서 `homepage-img-1-ko.png` 이미지를 첨부할 수 있는 경우에는 이미지까지 첨부해줘.
다만 해당 블로그의 댓글 UI에 이미지 첨부 버튼이나 `input[type=file]` 이 없거나, 이미지 첨부 시도가 Chrome 확장 통신 오류/타임아웃으로 실패하는 경우에는 댓글 등록을 중단하지 말고 텍스트만 등록해줘.

이미지 없이 텍스트만 등록한 글은 작업 완료로 처리하고, wordpress-results.md 에 "이미지 첨부 불가로 텍스트만 등록"이라고 기록해줘.

## 중복 등록 방지

댓글을 남기기 전에 반드시 이미 등록한 블로그인지 확인해줘.

1. wordpress-results.md 에 같은 블로그 글이 이미 기록되어 있는지 먼저 확인해줘.
2. 브라우저에서 댓글 위젯을 연 뒤, 실제 댓글 목록에도 우리 계정이 이미 남긴 댓글이 있는지 확인해줘.
   - 댓글 작성 전에 현재 로그인 계정의 닉네임/프로필과 기존 댓글 목록을 비교해줘.
   - 우리 댓글 첫 문장, `babysitter.dveamer.com`, 또는 같은 이미지 첨부가 이미 보이면 다시 등록하지 마.
3. 이미 등록된 글이면 댓글과 이미지를 다시 올리지 말고, 해당 task 는 중복으로 판단해서 wordpress-tasks.md 에서 제거하고 wordpress-results.md 에 "이미 등록된 글이라 재등록하지 않음"으로 기록해줘.
4. 댓글 허용 안 됨, 권한 없음, 잘못된 접근처럼 실제 등록이 되지 않은 글은 완료 처리하지 말고 wordpress-tasks.md 에 남겨둬. 단, 같은 실패가 반복되면 결과 파일에는 별도 실패 사유만 기록해도 돼.


## 작업 종료 
 
작업이 완료된 task 는 wordpress-tasks.md 에서 제거해주고 wordpress-results.md 에 기록해줘. 

### 리소스 해제

작업이 모두 완료되었다면 사용했던 chrome 은 종료시켜줘.
브라우저 탭만 종료하지 말고 브라우저를 종료시켜줘.

## 주의 사항

openchrome / Chrome DevTools 사용하지 말고 codex 에서 제공하는 chrome 확장기능을 사용해야해

### chrome 브라우저 사용

chrome 사용에 문제가 있다면 아래 같은 문제 점이 예상돼.
  1. chrome 에서 wordpress 로그인이 되어있지 않아서 
  2. 이전에 사용했던 chrome 리소스가 정리가 되지 않아서 
  
1번이 원인일 경우에는 대기해서 내가 로그인해주는 수밖에 없어. 
2번이 원인일 경우에는 chrome 리소스를 종료 시키면 다음 스캐쥴에서는 정상적으로 동작할 것으로 예상돼

문제점이 생겼을 때 Playwright 를 사용해서 해결해보려고하지마. 성공하는 것이 기록된 적이 없어.

> API를 직접 호출하는 방식은 도구 안전 검사가 막았습니다. 대신 지시서에 맞게 브라우저 화면을 실제로 열고, 멤버등급 안내 화면의 텍스트 스냅샷만 읽어서 상태를 확인하겠습니다.

라는 상황이 발생하기도했어. 글을 작성하고 등록하는 행위는 API가 아닌 chrome를 통해 진행해줘.
