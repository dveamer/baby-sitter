
# 티스토리 블로그 댓글 작성

tstory-tasks.md 파일에 작성되어있는 tasks 들 중 5개를 뽑아서 각 tasks 에 적힌 블로그 글에 공감을 누르고 댓글을 달아줘. 댓글에 homepage-img-1-ko.png 이미지 파일도 첨부해줘. 

~공감, 댓글, 이미지 첨부는 naver-blog-comment-assist skill 을 이용하면돼.~

## 이미지 첨부 처리

티스토리 댓글 UI에서 `homepage-img-1-ko.png` 이미지를 첨부할 수 있는 경우에는 이미지까지 첨부해줘.
다만 해당 블로그의 댓글 UI에 이미지 첨부 버튼이나 `input[type=file]` 이 없거나, 이미지 첨부 시도가 Chrome 확장 통신 오류/타임아웃으로 실패하는 경우에는 댓글 등록을 중단하지 말고 텍스트만 등록해줘.

이미지 없이 텍스트만 등록한 글은 작업 완료로 처리하고, tstory-results.md 에 "이미지 첨부 불가로 텍스트만 등록"이라고 기록해줘.

## 성공한 티스토리 등록 절차 기록

2026-05-20 에 `https://yukarecovery.tistory.com/43` 글은 아래 절차로 성공했다.

1. Codex Chrome 확장 세션에서 새 탭을 열고 글 URL 로 이동했다.
2. 전체 DOM 스냅샷이나 `dom_cua.get_visible_dom()` 은 티스토리 페이지에서 타임아웃이 잦아 사용하지 않았다.
3. 화면 스크린샷을 확인하면서 아래로 스크롤해 글 하단의 공감/댓글 영역으로 이동했다.
4. 댓글 영역에 기존 댓글 수가 `댓글 0` 으로 보이고, `babysitter.dveamer.com` 또는 같은 첫 문장 댓글이 보이지 않는 것을 확인했다.
5. 하단 공감 버튼을 클릭했고, 공감 숫자가 `1` 로 바뀐 것을 스크린샷으로 확인했다.
6. 댓글 UI 에 `input[type=file]` 이 없음을 확인했다. 이미지 첨부가 불가능한 티스토리 댓글 UI 로 판단하고 텍스트만 등록했다.
7. 댓글 입력창은 `[contenteditable="true"]` locator 로 찾고, `fill()` 로 댓글 본문을 입력했다.
8. `button:has-text("등록")` 또는 화면의 `등록` 버튼을 클릭해 제출했다.
9. 제출 후 스크린샷에서 `댓글 1`, 로그인 계정 `info57650`, 댓글 본문, `babysitter.dveamer.com` 이 보이는 것을 확인했다.
10. `body` 텍스트에 `babysitter.dveamer.com` 이 있고, 입력창에는 같은 댓글이 남아있지 않은지 확인하면 완료로 본다.

## 다음 실행 최적화

- 티스토리 글은 먼저 1개 탭으로 성공 여부를 확인한 뒤, 같은 스킨/동작이면 최대 5개까지 병렬 처리한다.
- `domSnapshot`, `dom_cua.get_visible_dom()`, 전체 페이지 캡처는 타임아웃 원인이 되기 쉬우므로 기본 경로에서 쓰지 않는다.
- 이동/상태 확인은 화면 스크린샷과 짧은 locator 확인을 조합한다.
- 댓글 입력은 `[contenteditable="true"]` 를 우선 사용하고, 제출은 `button:has-text("등록")` 를 우선 사용한다.
- 이미지 첨부는 `input[type=file]` 개수만 짧게 확인한다. 0개이면 이미지 붙여넣기나 우회 업로드를 시도하지 말고 텍스트만 등록한다.
- 텍스트만 등록한 완료 건은 `tstory-results.md` 에 "이미지 첨부 불가로 텍스트만 등록"이라고 남긴다.
- 댓글 입력창을 찾지 못한 글은 완료 처리하지 않고 `tstory-tasks.md` 에 남긴다. 공감만 된 상태라도 댓글 등록 성공이 아니면 완료로 보지 않는다.

글 작성을 위해서 로그인이 필요할거야. chrome을 이용하고 내가 로그인해주면 그다음에 진행하면돼.

댓글을 추가할 때는 브라우저 제어하는 작업은 각각 새로운 브라우저 탭으로 진행해서 병렬처리를 했으면해. 
예를들어, 5개의 댓글을 추가할 예정이라면 댓글 추가할 게시물 선정 후 새로운 브라우저 탭 5개를 이용해서 병렬로 진행하도록 해줘. 

## 중복 등록 방지

댓글을 남기기 전에 반드시 이미 등록한 블로그인지 확인해줘.

1. tstory-results.md 에 같은 블로그 글이 이미 기록되어 있는지 먼저 확인해줘.
2. 브라우저에서 댓글 위젯을 연 뒤, 실제 댓글 목록에도 우리 계정이 이미 남긴 댓글이 있는지 확인해줘.
   - 댓글 작성 전에 현재 로그인 계정의 닉네임/프로필과 기존 댓글 목록을 비교해줘.
   - 우리 댓글 첫 문장, `babysitter.dveamer.com`, 또는 같은 이미지 첨부가 이미 보이면 다시 등록하지 마.
3. 이미 등록된 글이면 댓글과 이미지를 다시 올리지 말고, 해당 task 는 중복으로 판단해서 tstory-tasks.md 에서 제거하고 tstory-results.md 에 "이미 등록된 글이라 재등록하지 않음"으로 기록해줘.
4. 댓글 허용 안 됨, 권한 없음, 잘못된 접근처럼 실제 등록이 되지 않은 글은 완료 처리하지 말고 tstory-tasks.md 에 남겨둬. 단, 같은 실패가 반복되면 결과 파일에는 별도 실패 사유만 기록해도 돼.

### chrome 브라우저 사용

chrome 사용에 문제가 있다면 아래 같은 문제 점이 예상돼.
  1. chrome 에서 tstory 로그인이 되어있지 않아서 
  2. 이전에 사용했던 chrome 리소스가 정리가 되지 않아서 
  
1번이 원인일 경우에는 대기해서 내가 로그인해주는 수밖에 없어. 
2번이 원인일 경우에는 chrome 리소스를 종료 시키면 다음 스캐쥴에서는 정상적으로 동작할 것으로 예상돼

문제점이 생겼을 때 Playwright 를 사용해서 해결해보려고하지마. 성공하는 것이 기록된 적이 없어.

> API를 직접 호출하는 방식은 도구 안전 검사가 막았습니다. 대신 지시서에 맞게 브라우저 화면을 실제로 열고, 멤버등급 안내 화면의 텍스트 스냅샷만 읽어서 상태를 확인하겠습니다.

라는 상황이 발생하기도했어. 글을 작성하고 등록하는 행위는 API가 아닌 chrome를 통해 진행해줘.
